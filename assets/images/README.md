# Petunjuk Penempatan Gambar Produk (Format PNG)

Silakan letakkan foto produk berformat PNG (dengan latar belakang transparan / cut-out bersih) ke dalam folder ini dengan penamaan berikut:

1. **`botolan.png`**  
   Untuk menu **SERI BOTOLAN** (koleksi botol kopi cold brew / literan).

2. **`es-krim.png`**  
   Untuk menu **ES KRIM** (soft serve cone / sundae cup).

3. **`signature.png`**  
   Untuk menu **SIGNATURE COFFEE** (gelas kopi iced latte / sea salt cream).

4. **`makanan.png`**  
   Untuk menu **CORAL BITES** (nasi bowl / ayam geprek / fries).

---
*Tip*: Gambar dengan resolusi rasio sekitar 1:1 atau 3:4 dengan background transparan akan menyatu sempurna dengan latar belakang web dan efek animasi scroll fade in/out.
